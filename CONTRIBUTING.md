# Contributing

Contributions are welcome when they preserve exact provenance and attribution.

- Do not add weights, container layers, credentials, or copied proprietary material.
- Do not call the ShapleyMCG checkpoint OSI open source.
- Keep the required ShapleyMCG attribution notice intact.
- Cite primary sources for attribution and performance claims.
- Start a new benchmark lineage when model, template, image, engine, GPU, context, or decoding changes.
- System-changing remediation must be opt-in, reversible, evidence-driven, and include rollback.
- Run `scripts/ci.sh` before opening a pull request.
