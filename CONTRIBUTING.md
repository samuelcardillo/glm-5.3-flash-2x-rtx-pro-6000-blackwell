# Contributing

Contributions are welcome when they preserve exact provenance, attribution, safety boundaries, and evidence quality.

- Do not add model weights, draft weights, container layers, credentials, raw private receipts, or copied proprietary material.
- Preserve the DFlash2 CC BY-NC-ND 4.0 research/evaluation boundary and commercial-license warning.
- Do not describe the composed deployment as Apache-only or fully source-audited.
- Cite primary sources for attribution and performance claims.
- Start a new benchmark lineage whenever model, draft, template, image, runtime, GPU, power, context, or decoding changes.
- Keep prompts, responses, reasoning, hostnames, paths, GPU UUIDs and PCI IDs out of public evidence.
- System-changing remediation must be opt-in, reversible, evidence-driven, and include rollback.
- Run `scripts/ci.sh` before opening a pull request.
